## Rule

No vendor name or mark is added anywhere in a Usance public surface without:

1. Identifying the specific claim being made (integration, evidence, proof level — never
   "partner," "sponsor," or "backed by" unless a vendor has independently confirmed that
   relationship in writing);
2. For a visual mark: locating the vendor's official brand kit, confirming the permitted variant
   and whether recolouring/resizing is allowed, and recording the source URL and fetch date here;
3. Recording the entry in the table above before the surface ships.

Text-only mentions (as currently used) still name only vendors with real, current, implemented
evidence in this repo — see the claims matrix in `docs-site/networks.md` and
`docs-site/institutional.md`.
